Objetivo: Desenvolver uma aplicação completa em React + FastAPI, chamada LeadMap, que busca empresas no Google Maps (Google Places API), identifica as que não possuem site, e permite exportar os resultados para CSV.
O sistema será vendido como script direto (licença única), e deverá ser limpo, moderno e fácil de configurar localmente.

🎯 Descrição do Projeto

LeadMap é uma ferramenta de prospecção automática que permite encontrar empresas sem site a partir de um termo de busca como “advogado em São Paulo”, “clínica odontológica em Recife”, etc.
O sistema usa a Google Places API para retornar os dados e apresenta tudo em um painel organizado.

O usuário insere o termo no frontend → o backend faz a busca → exibe os resultados com filtros → permite exportar para CSV.

⚙️ Tecnologias e Stack

Frontend:

React (com Vite ou Next.js, escolha a mais simples)

TailwindCSS (estilo limpo e escuro)

Axios (para chamadas à API)

shadcn/ui para componentes

Lucide-react para ícones

Backend:

Python + FastAPI

requests (para chamadas à API do Google)

pandas (para manipulação e exportação CSV)

Uvicorn (servidor)

dotenv (configuração da API_KEY)

Infraestrutura e Entrega:

Projeto deve rodar localmente via Docker (backend + frontend)

Um único comando docker-compose up inicia tudo

Entregar README.md com passo a passo de uso e configuração

🧩 Funcionalidades Obrigatórias
Frontend

Campo de busca (“Digite o tipo de negócio e cidade”)

Botão “Buscar”

Loader de carregamento

Tabela com colunas:

Nome

Telefone

Endereço

Website

Avaliação

Link do Google Maps

Filtro automático: mostrar apenas empresas sem website

Botão “Exportar CSV”

Interface moderna, dark e minimalista

Exibir contagem de resultados e tempo de execução

Backend

Endpoint /search (POST)

Parâmetro: query

Retorna JSON com lista de empresas

Serviço que consome a Google Places API:

Busca pelo termo informado

Pega os place_id e consulta detalhes de cada empresa

Retorna nome, telefone, endereço, website, rating e URL do Maps

Endpoint /export (POST)

Recebe lista e exporta CSV (via pandas)

Controle de erros (limite da API, sem resultados, etc.)

Arquivo .env com GOOGLE_API_KEY

Configuração pronta para Docker e execução local (docker-compose up)
